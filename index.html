Method: pulled directly from app.bosta.co/api/v0/deliveries/search filtered by Business ID + Picked At (1–25 Oct 2026). The business list comes from the Merchants tab of the Working Plan 5-7 sheet. DSR% = Delivered ÷ (Delivered + RTO) among this month's picked-up orders; RTO% = RTO ÷ (Delivered + RTO). Branch = the RTO order's assigned hub. Early in a month, many orders are still in transit, so RTO% is naturally less settled than later in the month.
Not included: transfer/handover document (محول) status per RTO order — that flag isn't exposed on the deliveries list/search response, only inside each order's own timeline, so it wasn't pulled for all businesses in this run.
Trend arrows (▲/▼): compare each business's RTO% in this update to its RTO% in the last saved update (here: 1–18 Oct) — ▲ green = RTO% went down, ▼ red = RTO% went up, → grey = essentially unchanged (<0.5pp), • = no prior value to compare against.
